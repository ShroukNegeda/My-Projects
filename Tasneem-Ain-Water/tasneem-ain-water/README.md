# Tasneem Ain — موقع مياه معدنية (Next.js 16)

موقع تجارة إلكترونية كامل لبيع المياه المعدنية فى المملكة العربية السعودية، مبنى بـ **Next.js 16.1.4** (App Router)،ىبتصميم عربي RTL احترافى بألوان لبني/أزرق.


## المميزات

-  صفحة رئيسية احترافية بتصميم مميز (موجات مائية متحركة، قارورة عائمة، ألوان لبنى وأزرق)
-  تسجيل دخول / إنشاء حساب بالإيميل والباسورد (جلسة محمية بـ JWT في كوكيز httpOnly)
-  سلة مشتريات مع إمكانية زيادة/إنقاص الكمية، بتتحفظ حتى لو قفلت المتصفح
-  صفحة "طلباتى" لكل عميل يشوف فيها كل طلباته وحالتها
-  **طريقتين دفع**: الدفع عند الاستلام (COD)، وتحويل بنكى يدوى (الأدمن يأكده من لوحة التحكم بعد استلام المبلغ)
- 🛠️ لوحة تحكم أدمن كاملة:
  - نظرة عامة (إحصائيات الطلبات والإيرادات)
  - قائمة كل الطلبات مع بيانات العميل والموقع وطريقة وحالة الدفع
  - صفحة تفاصيل لكل طلب (المنتجات، العنوان بالتفصيل، رقم عملية التحويل لو موجود)، وإمكانية تغيير حالة الطلب وحالة الدفع
  - إدارة المنتجات: إضافة منتج جديد، تعديل السعر/الاسم، إخفاء منتج — وبيظهر فورًا في الصفحة الرئيسية

## التقنيات المستخدمة

| الجزء | التقنية |
|---|---|
| Frontend + API | Next.js 16.1.4 (App Router + Route Handlers) |
| التصميم | Tailwind CSS |
| قاعدة البيانات | SQLite (عبر `node:sqlite` المدمج في Node.js) — ملف واحد محلي، مفيش سيرفر داتابيز منفصل |
| المصادقة | JWT + كوكيز httpOnly + تشفير الباسورد بـ bcrypt |
| الدفع | الدفع عند الاستلام + تحويل بنكى يدوى |

## التشغيل محليًا

```bash
npm install
npm run seed
npm run dev
```

افتحي `http://localhost:3000`.

> محتاجة Node.js نسخة 22.13 أو أحدث (لدعم `node:sqlite` المدمج من غير أي تركيب إضافى).


## إعداد بيانات التحويل البنكي

طريقة "تحويل بنكى" بتعرض بيانات حسابك للعميل مباشرة بعد تأكيد الطلب، من غير أي بوابة دفع خارجية. 

```js
export const BANK_DETAILS = {
  bankName: 'اسم البنك',
  accountName: 'اسم صاحب الحساب',
  iban: 'رقم الآيبان',
  accountNumber: 'رقم الحساب',
};
```


## هيكل المشروع

```
app/
  page.jsx                    الصفحة الرئيسية
  login/ register/            تسجيل الدخول وإنشاء حساب
  cart/                       السلة
  checkout/                   بيانات التوصيل + اختيار طريقة الدفع
  checkout/success/           تأكيد الطلب (وبيانات التحويل البنكى لو اتختارت)
  account/                    طلبات العميل
  admin/                      لوحة تحكم الأدمن (محمية بالكامل)
  api/                        كل الـ API routes (auth, products, orders)
components/                   مكونات الواجهة القابلة لإعادة الاستخدام
context/                      Cart + Auth context (React)
lib/
  db.js                       إعداد قاعدة البيانات SQLite والجداول
  auth.js                     تسجيل الدخول، الجلسات، تشفير الباسورد
  siteConfig.js                بيانات التحويل البنكى
scripts/seed.js                سكريبت إنشاء الأدمن والمنتجات التجريبية
proxy.js                       حماية صفحات /admin و /checkout و /account
```
